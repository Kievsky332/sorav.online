## Установка (Linux)
У вас должны быть установлены [зависимости проекта](https://github.com/OkulusDev/Oxygen#зависимости)

1. Клонирование репозитория 

```git clone https://github.com/Kievsky332/sorav.online.git```

2. Откройте сайт

```Откройте index.html через любой удобный браузер.```
